# GYMMY FOODS website

A zero-cost, responsive static starter site for GYMMY FOODS.

## Run locally
Double-click `index.html`, or run:

```bash
python -m http.server 5500
```
Then open http://localhost:5500

## Free hosting — recommended: Cloudflare Pages
1. Create a GitHub repository, for example `gymmy-foods-website`.
2. Upload all files in this folder to the repository root.
3. In Cloudflare, go to **Workers & Pages → Create → Pages → Connect to Git**.
4. Select the repository.
5. This is a plain static site. No framework/build command is required.
6. Deploy. You will receive a free `*.pages.dev` address.

## Alternative: GitHub Pages
1. Upload these files to a public GitHub repository.
2. Open **Settings → Pages**.
3. Choose deployment from your main branch/root.
4. GitHub gives you a free `*.github.io` URL.

## Before public launch
- Replace `https://gymmyfoods.pages.dev` in `index.html`, `robots.txt`, `sitemap.xml` and the JSON-LD block if your final address changes.
- After ROC approval, replace the footer registration placeholder with the official company registration number.
- Confirm every product/health/nutrition claim against the actual product formulation and applicable Sri Lankan food-labeling rules before publishing it.
- If you later buy a custom domain, connect it through Cloudflare Pages or GitHub Pages.
